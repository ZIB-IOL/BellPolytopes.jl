BellPolytopes.jl: probability analyticity correction

Probability workflow
--------------------
Enable shr2 with prob=true in bell_frank_wolfe, its callback, and
nonlocality_threshold. The residual uses the Euclidean norm of the full
probability tensor, with axes (outputs..., inputs...). The new exported
probability_ball_radius computes the uniform-noise Bell-local radius without
enumerating vertices or constructing a covariance matrix. Its bipartite formula
matches SNOOPJ.jl; the multipartite extension follows the same covariance proof.
SNOOPJ.jl/ and notes/ were used only as read-only references.

The default radius is selected automatically (unit radius for correlations).
Explicit positive radii remain supported; probability corrections about
nonuniform noise require a caller-supplied proven radius. Normalization and
no-signaling conditions are checked numerically. Positivity is not required of
the finite target. These are numerical corrections, not interval certificates.

Compensation remains explicit: q = shrinking_target(p, eta; prob=true).
Its in-place form supports exact aliasing. The map assumes local measurement
shrinking toward uniform output responses and agrees with the existing binary
marginal-correlation map. Passing shr2 never transforms the input tensor.
Use shr2 = eta.^2 for displayed global bounds; solver inequalities and returned
thresholds still concern the finite target q. Multiply a returned finite lower
bound by prod(eta) to obtain its measurement-shrunk white-noise bound.

White-noise probability threshold searches now apply the residual correction
by default. analyticity=false retains the numerical bracket. Returned models
mix the original model with uniform noise using constant-output deterministic
atoms, avoiding enumeration over all setting-dependent strategies. Their
remaining approximation error scales by the correction factor. Nonwhite-noise
thresholds retain the existing uncorrected returned-model convention.

Symmetry-reduced coordinates are inflated from collected coefficients, without
mutating cached full-data buffers. Affine checks account for the precision of
the original data when a final iterate is promoted to BigFloat.

Validation
----------
Added 255 probability checks covering independently enumerated vertex/covariance
radii and ball decompositions, heterogeneous and multipartite scenarios,
Float32/Float64/BigFloat/rational compensation, aliasing, the physical shrinking
identity, affine validation, callbacks, symmetry, custom noise/radii, displayed
bounds, threshold correction, and returned-model reconstruction.
The existing correlation tests remain part of the complete regression suite.

The complete suite passed with Julia 1.13.1 and --check-bounds=yes: 2,846
checks (15 original checks and 2,831 source-audit regressions).
